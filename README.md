# tinycert

A tiny command-line Certificate Authority for generating development and internal TLS certificates.

## Example

Initialize a new Certificate Authority:

```bash
tinycert init
```

Issue a certificate for localhost:

```bash
tinycert issue \
    --cn localhost \
    --san localhost \
    --san-ip 127.0.0.1
```

## Usage

```text
tinycert <command> [options]
```

## Commands

### `init`

Creates a new Certificate Authority (CA) by generating a root certificate and private key.

#### Options

```text
--ca-cert <file>    Output filename for the CA certificate (default: ca.crt)
--ca-key <file>     Output filename for the CA private key (default: ca.key)
--force             Overwrite existing CA files
```

#### Examples

Initialize a new CA:

```bash
tinycert init
```

Generate a new CA even if one already exists:

```bash
tinycert init --force
```

Use custom output filenames:

```bash
tinycert init \
    --ca-cert company-root.crt \
    --ca-key company-root.key
```

---

### `issue`

Issues a new server certificate signed by the configured CA.

#### Options

```text
--cn <name>                 Certificate Common Name (CN)
--cnf <file>                Certificate configuration file
--days-valid <days>         Certificate validity (default: 365)
--out-directory <dir>       Output directory
--san <dns...>              One or more DNS Subject Alternative Names
--san-ip <ip...>            One or more IP Subject Alternative Names
```

#### Examples

Issue a certificate:

```bash
tinycert issue --cn localhost
```

Issue a certificate with DNS Subject Alternative Names:

```bash
tinycert issue \
    --cn api.local \
    --san api.local localhost
```

Issue a certificate with DNS names and IP addresses:

```bash
tinycert issue \
    --cn api.local \
    --san api.local localhost \
    --san-ip 127.0.0.1 192.168.1.100
```

Specify the validity period and output directory:

```bash
tinycert issue \
    --cn api.local \
    --days-valid 730 \
    --out-directory ./certs
```

Issue a certificate using a configuration file:

```bash
tinycert issue --cnf server.cnf
```

---

### `verify`

Verifies a certificate against the configured Certificate Authority.

```bash
tinycert verify <certificate>
```

> **Note**
>
> This command is currently under development.

## Generated Files

Running `init` creates:

```text
ca.crt
ca.key
```

Running `issue` creates:

```text
<common-name>.crt
<common-name>.key
```

## Notes

* Generated private keys should be treated as secrets.
* Do not commit generated certificates or private keys unless they are intended for testing.
* Certificates generated by `tinycert` are intended for development and internal environments.

## Build

```bash
dotnet build
```

## Run

Initialize a Certificate Authority:

```bash
dotnet run -- init
```

Issue a certificate:

```bash
dotnet run -- issue --cn localhost --san localhost --san-ip 127.0.0.1
```
